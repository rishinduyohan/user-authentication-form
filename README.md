A modern, secure, and fully responsive User Authentication Form featuring Login and Sign-Up interfaces. This project focuses on providing a seamless user experience with real-time validation and a clean, aesthetic design.

[View Live Demo](https://rishinduyohan.github.io/user-authentication-form/) · [Report Bug](https://github.com/rishinduyohan/user-authentication-form/issues) · [Request Feature](https://github.com/rishinduyohan/user-authentication-form/issues)

---

## ✨ Features

- **🚀 Dual Interface:** Smooth transition between Login and Registration forms.
- **🛡️ Real-time Validation:** Client-side checks for email format, password strength, and empty fields.
- **👁️ Password Visibility:** Toggle button to show/hide passwords for better UX.
- **📱 Fully Responsive:** Optimized for all screen sizes (Mobile, Tablet, Desktop).
- **🎨 Modern UI:** Clean design with custom CSS animations and focus effects.
- **⚡ Lightweight:** Built with vanilla technologies for maximum performance.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for accessibility.
- **CSS3:** Custom styling using Flexbox/Grid and CSS variables for easy theming.
- **JavaScript (ES6+):** Form logic, validation, and DOM manipulation.
- **Google Fonts:** For modern typography.
- **FontAwesome:** For intuitive iconography.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
- Any modern web browser (Chrome, Firefox, Edge, etc.)
- A code editor (VS Code recommended)

### Installation

 **Clone the repository:**
   ```bash
   git clone [https://github.com/rishinduyohan/user-authentication-form.git](https://github.com/rishinduyohan/user-authentication-form.git)
   ```
 ###  Navigate to the project directory:
    ```bash
    cd user-authentication-form

    Open the project: Simply open index.html in your browser.
    ```;

  ### 📂 Project Structure
```bash

user-authentication-form/
├── assets/             # Images and Icons
├── css/                # Stylesheets
│   └── style.css
├── js/                 # JavaScript logic
│   └── script.js
├── index.html          # Main entry point
└── README.md           # Project documentation
```
